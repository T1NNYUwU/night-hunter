7 Nights Hunter

เสนอหัวข้อโครงงานจบ ป.ตรี วิทยาการคอมพิวเตอร์ · ทีม 3 คน · ประมาณ 1 ภาคเรียน · 17 พ.ย. 2026

ในย่อหน้าเดียว

เราสร้าง ปีศาจ AI ที่ตาบอดและล่าผู้เล่นด้วยเสียงอย่างเดียว ในเกม co-op สยองขวัญบน Roblox ปีศาจไม่เคยรู้ตำแหน่งจริงของผู้เล่น ต้องอนุมานจากเสียง นี่คือปัญหา การตัดสินใจภายใต้ข้อมูลไม่ครบ (partially observable)

โครงงานจะ เปรียบเทียบสมอง AI 4 แบบ ตั้งแต่กฎง่าย ๆ จนถึงการวางแผนแบบ POMCP ที่เรียนรู้พฤติกรรมผู้เล่นจากข้อมูล วัดผล ทั้งในตัวจำลองและกับผู้เล่นจริง ผ่านระบบเก็บข้อมูลที่ทำงานอยู่แล้ว

กลุ่มอื่นเทียบโมเดลบนชุดข้อมูล งานนี้ก็เทียบโมเดลเหมือนกัน แต่ทดสอบในระบบที่คนเล่นได้จริง และถามคำถามเพิ่มว่า "ผลจากตัวจำลองตรงกับผลจากมนุษย์แค่ไหน"

1. คำถามวิจัย

RQ1
การติดตามด้วยความน่าจะเป็น (belief) และการวางแผน (POMCP) จับผู้เล่นได้ดีกว่ากฎธรรมดาแค่ไหน
RQ2
โมเดลพฤติกรรมผู้เล่นที่เรียนรู้จากข้อมูล (opponent model) ช่วยเพิ่มอีกเท่าไร
RQ3
ผลจากบอทในตัวจำลอง ต่างจากผลกับคนจริงเท่าไร (sim-to-real gap)
RQ4
(ถ้ามีเวลา) ปีศาจที่ฉลาดขึ้นทำให้กลัวขึ้น โดยไม่รู้สึกว่า "โกง" หรือไม่

2. ปีศาจคิดอย่างไร

ศัตรูในเกมส่วนใหญ่รู้ตำแหน่งผู้เล่นตลอดแล้วแกล้งทำเป็นไม่รู้ ปีศาจของเราไม่รู้จริง ทุก 0.5 วินาทีมันคิดเป็น 3 ชั้น:

1. รับรู้ (belief)
Particle filter 300 ตัวต่อผู้เล่น อัปเดตจาก "ได้ยินเสียงที่ห้องนี้" / "ฟังแล้วเงียบ" / "เปิดตู้แล้วว่าง" ได้แผนที่ว่าผู้เล่นน่าจะอยู่ห้องไหนกี่ %
▼
2. ตัดสินใจ
rule ไปที่เสียงล่าสุด · belief ไปห้องที่น่าจะมีคนมากสุดเทียบกับระยะทาง · pomcp จำลองอนาคตหลายร้อยแบบ (Monte Carlo tree search) แล้วเลือกทางที่จับได้เร็วที่สุด
▼
3. รู้จักผู้เล่น
Opponent model ทำนายว่าผู้เล่นจะหนี ซ่อน หรืออยู่นิ่ง เมื่อปีศาจอยู่ใกล้แค่ไหน เรียนรู้จากข้อมูลการเล่นจริง

3. สิ่งที่มีอยู่แล้ว

ส่วนสถานะรายละเอียด
เกม co-op 7 คืน บน Robloxเล่นได้คฤหาสน์ 3 ชั้น 25 ห้อง, ซ่อนในตู้, ภารกิจ, ไฟฉาย, ร้านค้า
กราฟของบ้านใช้งานอยู่52 node (25 ห้อง + 27 ที่ซ่อน) ใช้ร่วมกันทั้งเกม ตัวจำลอง และ backend

ตัวจำลอง (headless)ใช้งานอยู่บอท 4 สไตล์ เล่นหลายร้อยคืนในไม่กี่วินาที ใช้โค้ดสมองตัวเดียวกับเกม

ทิศทางที่น่าสนใจ

  • การวางแผน (POMCP) ชนะการติดตามอย่างเดียวชัดเจน
  • Opponent model ให้ผลมากกว่าการวางแผน และเมื่อโมเดลแม่นพอ การวางแผนช่วยน้อยลง
  • Opponent model ทำนายผู้เล่นสไตล์ที่ไม่เคยเห็นได้ 3 ใน 4 แบบ แต่ล้มเหลวกับผู้เล่นที่เดินมั่ว
  • ข้อมูลคนจริงตอนนี้ (27 คืน ผู้พัฒนาเล่นคนเดียว) ใช้เป็นหลักฐานไม่ได้ แต่บอกว่า บอทชนะคืนแรก 97% ส่วนคนชนะ 4% ตัวอย่างจริงของ sim-to-real gap (RQ3)

5. เส้นทางที่เลือกได้

ทางที่ 1 · แนะนำเป็นแกน

วิจัย AI ของเกม

เทียบสมอง AI ภายใต้ข้อมูลไม่ครบ

วัด: อัตราจับต่อคืน, เวลารอด

ใกล้กลุ่มอื่น: เทียบโมเดลแบบเดียวกัน

เสี่ยง: ต่ำ โค้ดพร้อม

ทางที่ 2 · เป็นเครื่องมือ

ระบบข้อมูล / ML

pipeline เก็บข้อมูล → ฝึก → ส่งโมเดลกลับเกม

วัด: log-likelihood บน holdout, ความแม่นการทำนาย

เสี่ยง: กลาง ต้องมีข้อมูลคนพอ

ทางที่ 3 · ส่วนเสริม

ประสบการณ์ผู้เล่น

ความกลัว ความยุติธรรม ความสนุก

วัด: แบบสอบถาม Likert, อัตราเล่นต่อ

เสี่ยง: สูง ต้องคนเยอะ วัดยาก

6. ระดับความลึก

ตื้น
รันการทดลองใหม่ในตัวจำลองบนบ้านปัจจุบัน เพิ่ม baseline (สุ่มเดิน / รู้ตำแหน่งจริง) ใช้สถิติแบบ paired ได้: ผลเทียบโมเดลที่ทำซ้ำได้ ครบในตัว
กลาง
แนะนำ
ตื้น + playtest กับคนจริง ~30 คน แบบ blind + วัด sim-to-real gap ได้: ตอบ RQ1–RQ3 ด้วยข้อมูลคน
ลึก
กลาง + วิธีใหม่ของเรา 1 อย่าง: ให้ POMCP จำลองเสียง (ปีศาจ "หยุดฟัง" เพื่อหาข้อมูล) · opponent model ที่ปรับตัวต่อผู้เล่นระหว่างเล่น · หรือฝึกบอทให้เลียนแบบคนจริงเพื่อลด sim-to-real gap ได้: มีส่วนที่เป็นงานใหม่ เขียนเป็นเปเปอร์ได้

9. ความเสี่ยง

ความเสี่ยงรับมือ
หาคนเล่นไม่พอลดเป้าเป็น 12–15 คนเล่นหลายรอบ, รายงานช่วงความเชื่อมั่นแทน p-value
ผู้เล่น Roblox มีเด็กplaytest ปิด เชิญเฉพาะคนอายุ 18+, ไม่เก็บชื่อหรือ user id (ระบบทำไว้แล้ว)
Roblox เปลี่ยน API / บริการbackend แยกจากเกม, ตัวจำลองรันได้โดยไม่ต้องใช้ Roblox
งานกราฟิกกินเวลาล็อกกราฟิกตั้งแต่สัปดาห์ 2 งานที่เหลือเป็นงาน AI และข้อมูล

10. คำถามถึงอาจารย์

  1. หัวข้อแนวนี้ (game AI + การทดลองกับคน) นับเป็นงานวิจัยพอสำหรับโครงงานจบไหม
  2. อาจารย์อยากให้ลึกระดับไหน ต้องมีส่วนที่เป็นวิธีใหม่ (ระดับลึก) หรือไม่
  3. งานที่ทำไปแล้วก่อนเทอม นับเป็นส่วนหนึ่งของโครงงานได้แค่ไหน และภาคมีกฎเรื่องใช้ AI ช่วยเขียนโค้ดอย่างไร
  4. การทดลองกับคน ต้องผ่านคณะกรรมการจริยธรรมของมหาวิทยาลัยหรือไม่
  5. ภาคใช้โครงสร้างโครงงาน 1 + 2 (สองเทอม) หรือจบในเทอมเดียว
