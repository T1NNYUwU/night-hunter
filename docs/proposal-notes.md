# บันทึกเตรียมเสนอโครงงาน (2026-11-15)

โครงงานจบ ป.ตรี สามคน ประมาณ 1 เทอม หัวข้อ: **7 Nights Hunter** ปีศาจตาบอดที่ล่าด้วยเสียง
(belief / POMCP / opponent model) + telemetry backend

สถานะ: **ยังไม่ได้ตัดสินใจ** คำถามทุกข้อด้านล่างรอคำตอบ (➡️ = ข้อที่แนะนำ)

## 1. สิ่งที่มีอยู่แล้ว

- เกม Roblox co-op 7 คืน, บ้านคฤหาสน์หลายชั้น, ระบบซ่อนตู้, ภารกิจต่อคืน
- สมองปีศาจ 3 แบบใช้ประสาทสัมผัสชุดเดียวกัน (`src/shared/HunterBrain.luau`)
  - `rule`: ไปที่เสียงล่าสุด ไม่มีเสียงก็สุ่มเดิน (baseline)
  - `belief`: particle filter ผู้เล่นละ 300 ตัว, เลือกห้องที่ (ความน่าจะเป็น / ระยะทาง) สูงสุด + กวาดห้องที่ไม่ได้ฟังนาน
  - `pomcp`: Monte Carlo tree search บน belief (Silver & Veness 2010), 200 simulations (ตัดที่ 4 ms, ขั้นต่ำ 50),
    มองไปข้างหน้า 30 วิ, ลึก 4 macro-action, γ 0.97, UCB1 c 0.5, observation ย่อเหลือ "จับได้ / ไม่เจอ"
  - opponent model (เปิด/ปิดได้): ทำนายก้าวถัดไปของผู้เล่นจาก "อยู่ห้อง/ตู้" × "ปีศาจห่างกี่ห้อง"
- Story mode (`src/server/Config.luau`): คืน 1–2 belief, 3–6 pomcp, 7 pomcp+model;
  ความเร็ว/การได้ยินเพิ่มตามคืน (`src/server/NightCycle.luau`: patrol 10→16, charge 15→20, hearing 0.75→1.0)
- Experiment mode: สุ่ม 1 เงื่อนไขต่อรอบ (rule / belief / pomcp / pomcp+model)
- Backend FastAPI + Postgres บน Render: รับข้อมูลทุกคืน, ฝึกโมเดล train/holdout, dashboard สถิติ
- ผลจากบอทในตัวจำลอง: ดู [m4-research.md](m4-research.md)

## 2. ข้อมูลจริงที่มี (pilot เท่านั้น)

จาก `/v1/stats` (2026-11-15): 27 คืน, **เล่นคนเดียว โดยผู้พัฒนาเอง**

| สมอง | คืน | ผู้เล่นชนะ | หมายเหตุ |
|---|---|---|---|
| belief | 25 (คืนที่ 1: 24, คืนที่ 2: 1) | 1/25 (4%) | คืนเฉลี่ย ~40 วิ = โดนจับ ~30 วิ หลังปีศาจตื่น |
| pomcp+model | 2 (คืนที่ 7) | 2/2 | น่าจะเป็นการทดสอบกระโดดไปคืนที่ 7 |

ข้อสรุป: ใช้เป็นหลักฐานในเล่มไม่ได้ (คนเดียว, ไม่มีเพื่อนชุบ) แต่บอกว่า
**คืนที่ 1 ยากเกินไปสำหรับคน** (บอทชนะ 97% คนชนะ 4%) และแพ้แล้วกลับคืนที่ 1 ทำให้ไม่เคยถึง pomcp

## 3. คำถามเรื่อง proposal

- **P1 แก่นของโครงงาน**: (ก) วิจัย AI ใช้เกมเป็น testbed (ข) พัฒนาเกม (ค) ระบบ telemetry/ML
  ➡️ (ก) โดยมี (ค) เป็นส่วนสนับสนุน
- **P2 บอกอาจารย์ว่าทำไปแล้วเยอะ**: ➡️ บอกตรง ๆ ว่าเป็น prototype; เทอมนี้คือประเมินกับคนจริง + ต่อยอด; เช็กกฎภาคเรื่องใช้ AI เขียนโค้ด
- **P3 แบ่งงาน 3 คน**: ➡️ คน 1 AI ปีศาจ (observation เสียงใน POMCP, model ปรับระหว่างเล่น)
  · คน 2 backend/ML/สถิติ (paired stats, pipeline, dashboard) · คน 3 เกม/UX + จัด playtest
- **P4 เวลา**: 1 เทอม (~16 สัปดาห์) หรือ โครงงาน 1 + 2 ➡️ ถามอาจารย์; วางแผน 16 สัปดาห์ไว้ก่อน
- **P5 รูปแบบ proposal**: ➡️ ถ้าไม่มี template ใช้โครงมาตรฐาน (ที่มา, วัตถุประสงค์, ขอบเขต, ทฤษฎี,
  วิธีดำเนินงาน, Gantt, ผลที่คาดว่าจะได้, อ้างอิง) ภาษาไทย .docx
- **P6 ของที่ถือไปคุย**: ➡️ สรุป 1 หน้า + คลิปเกมสั้น; สไลด์ทำตอนสอบ proposal

## 4. คำถามเรื่องความยากตามคืน

- **D1 แพ้แล้วเป็นอย่างไร**: ➡️ เล่นคืนเดิมซ้ำได้ 2 ครั้งต่อรอบ แล้วจึงกลับคืนที่ 1
- **D2 เป้าอัตราชนะ (คนจริง)**: ➡️ คืน 1 ≈ 85% ลดลงสม่ำเสมอถึงคืน 7 ≈ 35%
- **D3 ทำคืนแรกให้ง่ายขึ้น**: ➡️ ปีศาจหลับนานขึ้น (8→20 วิ), การได้ยินคืนแรก 0.75→0.55,
  คืนที่ 1 ใช้ `rule`, คำแนะนำบนจอคืนที่ 1
- **D4 ตารางสมอง story mode**: ➡️ คืน 1 rule · 2–3 belief · 4–5 pomcp · 6–7 pomcp+model
- **D5 เก็บข้อมูลวิจัย**: ➡️ experiment mode สุ่มสมอง **ต่อคืน** (ความเร็ว/การได้ยินยังตามเลขคืน)
- **D6 ปรับความยากอัตโนมัติ (DDA)**: ➡️ ไม่ทำ (ทำให้เทียบสมองไม่ยุติธรรม) ไว้ในงานอนาคต

## 5. คำถามเรื่องการวัดผล (ต้องวัดค่าได้)

- **M1 สมมติฐาน**: ➡️
  - H1 pomcp จับได้มากกว่า belief และ belief มากกว่า rule
  - H2 opponent model เพิ่มอัตราจับอีก
  - H3 ผลบอทในตัวจำลองต่างจากคนจริงเท่าไร (sim-to-real gap)
  - H4 สมองฉลาดขึ้นทำให้กลัวขึ้นแต่ไม่รู้สึกไม่ยุติธรรม
- **M2 ตัวชี้วัดหลัก**: ➡️ catch rate ต่อคืน เทียบสมองในคืนเดียวกัน (ตรงกับ M4 จึงเทียบบอทได้);
  รอง: เวลารอดจนโดนจับคนแรก (Kaplan–Meier / log-rank), downs ต่อคืน, เวลาคำนวณ (ms)
- **M3 ขนาดตัวอย่าง**: แยก 50% vs 30% ที่ α 0.05, power 80% ต้อง ~94 คืนต่อเงื่อนไข (~376 คืนรวม)
  ➡️ ผู้เล่น ~30 คน (คนละ ~10 คนจากสมาชิก 3 คน) × 2 รอบ; วิเคราะห์ mixed-effects (ผู้เล่นเป็น random effect);
  ได้น้อยกว่านั้นให้รายงาน CI
- **M4 ประสบการณ์ผู้เล่น**: ➡️ แบบสอบถามสั้นท้ายรอบ (ความกลัว 1–5, ความยุติธรรม 1–5,
  "รู้สึกว่ามันเรียนรู้การเดินของฉัน" ใช่/ไม่ใช่, ความสนุก 1–5); GEQ บางโมดูลถ้าอาจารย์ต้องการ
- **M5 จริยธรรม**: ➡️ playtest ปิด เชิญเฉพาะ อายุ 18+ เซิร์ฟเวอร์ส่วนตัว มีหน้าขอความยินยอม;
  ถามภาคเรื่องคณะกรรมการจริยธรรมวิจัยในมนุษย์
- **M6 baseline**: ➡️ rule (ล่าง) + เพิ่ม oracle (รู้ตำแหน่งจริง, เพดาน) และ random (พื้น) ในตัวจำลอง
  เพื่อรายงานว่า "แต่ละสมองปิดช่องว่างระหว่าง random กับ oracle ได้กี่ %"
