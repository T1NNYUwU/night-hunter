# ระบบที่ซ่อน (2026-10-09)

## ศึกษาจากเกมอื่น
| เกม | กลไกที่หยิบมา |
|---|---|
| Alien: Isolation | กลั้นหายใจตอนศัตรูอยู่ใกล้ (กลั้นนานไปตาพร่า), ศัตรูค้นตู้ที่สงสัย, ศัตรูเรียนรู้ว่าผู้เล่นชอบซ่อนตรงไหน |
| DOORS (Roblox) | ซ่อนในตู้/ใต้เตียง, เห็นข้างนอกผ่านช่องประตู, ลงโทษคนที่ซ่อนนานเกิน |
| Outlast | ศัตรูเปิดตู้/มุดดูใต้เตียงค้นหา |

แต่ปีศาจของเรา **ตาบอด** จึงแปลงจาก "ถูกเห็นตอนเข้าตู้" เป็น "ถูกได้ยินตอนเข้าตู้"
และ "ศัตรูเรียนรู้" ของ Alien Isolation เรามีอยู่แล้ว (opponent model)

## ผู้เล่นทำอะไรได้
| การกระทำ | ปุ่ม | ผล |
|---|---|---|
| เข้าที่ซ่อน | E ที่ตู้ / ที่โต๊ะ | กล้องย้ายไปมองผ่าน **ช่องระหว่างบานประตู** หรือ **ใต้ชายผ้า** หันได้นิดหน่อย |
| กลั้นหายใจ | กด SPACE ค้าง / ปุ่ม BREATH | ไม่มีเสียงหายใจ (อากาศหมดใน 6 วิ → หอบเสียงดัง) |
| ออก | E / ปุ่ม LEAVE | เสียงเอี๊ยดเบา ๆ |

## ปีศาจรู้ได้อย่างไร
| เสียง | ดัง | ได้ยินในห้องเดียวกัน |
|---|---|---|
| วิ่งพุ่งเข้าตู้ (ประตูกระแทก) | 1.0 | **แน่นอน + รู้ว่าตู้ไหน** → พุ่งมาเปิดทันที |
| เดินเข้า (เอี๊ยด) | 0.35 | ~30% |
| ย่องเข้า | 0.06 | แทบไม่ได้ยิน |
| หายใจ (ปีศาจอยู่ห้องเดียวกัน, ไม่กลั้น) | 0.12 ทุก 0.5 วิ | ~10% ต่อครั้ง → อยู่นาน ๆ ก็โดน |
| หอบ (กลั้นจนหมด) | 0.6 | ~55% |

- ความเร็วตอนเข้าใช้ **ความเร็วสูงสุดช่วงสั้น ๆ ก่อนกด E** (ลดลง 15 stud/วิ) เพราะคนวิ่งมาแล้วหยุดหน้าตู้ก่อนกด
  → วิ่งมาแล้วกดภายใน ~0.35 วิ ยังนับเป็น "วิ่งพุ่งเข้า"
- **ค้นเมื่อสงสัยพอ:** ถ้าความเชื่อของปีศาจว่ามีคนอยู่ในที่ซ่อนของห้องที่มันยืนอยู่ ≥ 30% มันจะเปิดดู
  (ใช้ทั้งในเกมและตัวจำลองผ่าน `HunterBrain.suspiciousSpot`)
- ผู้เล่นที่ซ่อนอยู่เห็น **แถบ "IT SUSPECTS THIS SPOT"** = ความเชื่อจริงของปีศาจเรื่องตู้ของตัวเอง (หัวใจเต้นแรงตามด้วย)
- ปีศาจเดินผ่านตู้ไม่จับ — จับได้เฉพาะตอนเปิด
- 1 ที่ซ่อนต่อ 1 คน

## ที่ซ่อน
- ตู้ 16 ใบ (ห้องละ 1) — โมเดล "Closet with Jack" ที่บานประตูแยกชิ้น เปิด/ปิดได้จริง
- โต๊ะผ้าคลุม 4 ตัว: ห้องสมุด, ห้องทำงาน, ครัว, ห้องอาหาร — โมเดล "Table With Tablecloth" (ผ้ายกขึ้นตอนปีศาจค้น)
- รายละเอียดการตรวจความปลอดภัย: [assets.md](assets.md)

## ทดสอบแล้ว (Studio)
- เข้าตู้ → กล้องอยู่ที่ช่องประตู, กลั้นหายใจ 2 วิ อากาศลด, ออก → ยืนหน้าตู้ มองเห็นตัวละครปกติ ✓
- เซิร์ฟเวอร์จำความเร็ว: หยุดวิ่งแล้ว 0.2 วิ = 19.4 (วิ่ง), 0.4 วิ = 14.4 (เดิน), 0.8 วิ = 3.6 (ย่อง) ✓ (แล้วปรับให้ลดช้าลง)
- ซ่อนเงียบ ๆ ในห้องเดียวกับปีศาจ → ปีศาจไปค้นตู้อื่น 6 ตู้ ไม่เจอ ✓
- ได้ยินเสียงกระแทกจากตู้ในห้องเดียวกัน → ความสงสัย 0.90 → พุ่งไป → เปิดประตู 100° → เจอ → ล้ม ✓
- telemetry บันทึก hide / search / unhide / down ครบ ✓
- **ยังไม่ได้ดูด้วยตา:** หน้าตาตู้/โต๊ะในบ้าน, overlay ช่องประตู/ผ้า, บนมือถือ
