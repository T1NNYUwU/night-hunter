# สัปดาห์ 2–3: บอทที่แข็งขึ้น + คืนแรกที่เล่นได้

อ้างอิง: [plan.md](../plan.md) หัวข้อ 7 (ไทม์ไลน์) และผลสปายก์ในหัวข้อ 9
**เงื่อนไขเสร็จ:** เล่นครบ 1 คืนแบบ co-op ใน Studio ได้โดยไม่มี error และตัวจำลองแยกความต่างของสมองได้ด้วย catch rate

## งาน

### T1 — บอทที่แข็งขึ้น (`src/shared/Sim.luau`)
- บอทได้ยินฝีเท้าปีศาจ (ปีศาจอยู่ห้องติดกัน → รู้) และ **ไม่เดินเข้าห้องที่ปีศาจอยู่**
- ปีศาจเข้าใกล้ (ห่าง ≤ 1 ห้อง) → บอทแนว hider/decoy รีบเข้าตู้ใกล้สุด, wanderer หนีไปห้องที่ไกลจากปีศาจ
- บอท decoy ปล่อยเสียงหลอก **ไปทางตรงข้ามกับตัวเอง** (ห้องที่ไกลจากตัวเองที่สุดในระยะ 2–3)
- เพิ่มตัวชี้วัด: อัตรารอดทั้งคืน (ไม่มีใครถูกจับเลย)
- **ตรวจ:** คืน 180 วินาที catch rate ของ rule ต้องไม่ติดเพดาน (เป้าอยู่ราว 30–80%) แล้วดูว่า belief ยังดีกว่าหรือไม่

### T2 — วงจรคืน (`src/server/NightCycle.luau` ใหม่)
- เฟส: `Day` (เตรียมตัว 20 วินาทีในเวอร์ชันนี้) → `Night` (180 วินาที) → `Report` (8 วินาที) → คืนถัดไป
- ภารกิจคืน: เก็บ **ลังเสบียง** ที่สุ่มวางในห้อง (คืนที่ n ต้องเก็บ 2 + n ลัง, สูงสุด 7 คืน)
- ผลคืน: ครบโควตาก่อนหมดเวลา = ผ่าน / ผู้เล่นล้มหมด = แพ้ (กลับไปคืน 1)
- สถานะทั้งหมดเป็น Attribute บน `Workspace.NightHunterState` (Phase, Night, PhaseEndsAt, Crates, CratesNeeded, Result)

### T3 — ล้มและช่วยฟื้น (`src/server/HunterService.luau`)
- โดนจับ = **ล้ม** (ไม่ถูกวาร์ป) เดินไม่ได้, ปีศาจไม่นับเป็นเป้าหมาย
- เพื่อนช่วยฟื้นด้วย ProximityPrompt กดค้าง 3 วินาที (ใช้บนมือถือได้)
- ฟื้นแล้วสมองปีศาจรีเซ็ตความเชื่อของคนนั้นไว้ที่จุดที่ฟื้น (เห็นตอนล้ม)
- ปีศาจเริ่มล่าเฉพาะช่วง `Night`, ช่วงกลางวันกลับไปห้อง 9 และหยุดนิ่ง

### T4 — HUD (`src/client/Client.client.luau`)
- แสดง: คืนที่, เฟส + เวลาที่เหลือ, ลังที่เก็บได้/ที่ต้องเก็บ, สถานะล้ม, ผลคืนตอนรายงาน
- ปุ่มดีบักเดิม (G / M / B) ยังอยู่

## การตรวจของรอบนี้
1. Unit checks เดิมยังผ่าน และตัวจำลองรันได้
2. Play ใน Studio: เกิด → กลางวันนับถอยหลัง → กลางคืนปีศาจออกล่า → เก็บลังได้ → โดนจับแล้วล้ม → (ทดสอบด้วยสคริปต์) ช่วยฟื้น → จบคืน → รายงาน → คืน 2
3. Output ไม่มี error
