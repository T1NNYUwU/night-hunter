# คฤหาสน์ 3 ชั้น (rework แมพ 2026-10-14)

แมพเก่า (ตาราง 4×4 ห้องสี่เหลี่ยมเท่ากัน) เหมือนเขาวงกต → ตอนนี้เป็น **คฤหาสน์ขนาดเล็ก 2 ชั้น + ชั้นใต้ดิน**
ห้องมีขนาดต่างกัน มีโถงหน้าบ้านสูง 2 ชั้นพร้อมบันไดสองทาง เพดานห้องสูง 14 studs (เดิม 12 และห้องเตี้ย)

## ทางขึ้นลง
- **โถง ↔ Landing**: บันได 2 ทางชิดผนังซ้าย/ขวา (กว้าง 6, ชั้นละ 1 stud, พรมแดง) ขึ้นไปบรรจบระเบียงชั้นบน พื้นชั้นบนตรงโถงเป็นช่องโหว่ จึงสูง 2 ชั้น มีโคมระย้า
- **Kitchen ↔ Cold Storage** และ **Study ↔ Boiler Room**: บันไดตรงชิดผนัง (ทางลงอยู่ปลายเหนือของห้อง, ปลายล่างเปิดสู่ห้องใต้ดิน) มีราวกันตก
- ใต้ดินเป็นวง: Boiler → Wine → Cold → (บันได) Kitchen → Living → Study → (บันได) Boiler

## คืนที่ 7: ของ → เสากลาง → กุญแจ → ประตูหน้า
1. มี **4 ของ** (Music Box, Silver Locket, Porcelain Doll, Old Photograph) ลอยเรืองแสงอ่อน ๆ ซ่อนอยู่คนละห้อง (ห่างจากโถง ≥ 2 ก้าว)
   กดค้างที่ของเพื่อเก็บ (ตัวใครตัวมัน แต่เอาไปวางแทนกันได้) ถ้าคนถือออกจากเกม ของกลับเข้าบ้าน
2. เอาไปวางที่ **แท่น (Altar)** หน้าเสากลางโถง กดค้างที่แท่น: ช่องเรืองแสงเขียวขึ้นทีละช่อง และ**ทุกครั้งที่วางทำเสียงดัง** (ปีศาจได้ยิน)
3. ครบ 4 ช่อง เสาคายกุญแจ วางอยู่บนแท่น กดค้างเพื่อหยิบ
4. ถือกุญแจ → กดค้างที่ **ประตูหน้า** ประตูเปิดออก = ชนะ (ถ้าคนถือกุญแจออกจากเกม กุญแจกลับไปที่แท่น)
- เหรียญ: ของละ 12, กุญแจ 15 (ใน `Items.REWARD`); โค้ดอยู่ใน `NightCycle.luau` หัวข้อ "the finale"
- เสาและแท่นสร้างโดย `HouseDecor.hallCentre` (Model ชื่อ `Pillar`) ตำแหน่งแก้ได้ที่ `HouseDecor.PILLAR_POS` / `ALTAR_POS`

## แสง
- ทั้งบ้านมืดลง: `Lighting.Brightness` 0.15 → 0.06, Ambient เข้มลง, โคมเพดานเดิม 0.32 → 0.22 (ระยะ 16 → 24 เพราะห้องใหญ่ขึ้น), หน้าต่างแสงจันทร์ 0.55 → 0.3
- ค่าทั้งหมดอยู่ที่ `HouseKit.luau` (โคม/โคมระย้า/เทียน/หน้าต่าง) และ `NightCycle.MOODS` (กลางวัน/กลางคืน)
- **ไฟฉายสว่างขึ้น**: Beam 7 → 12 (ระยะ 80), Halo 1.2 → 2.2 (ระยะ 45) ค่าอยู่ใน `StarterPack.Flashlight.Handle`
- **ไฟฉายไม่แกว่งตอนเดิน**: แสงที่ส่องจอตัวเองเป็นสำเนาที่ติดกับ **กล้อง** (`FlashlightBeam.luau`) ไม่ใช่มือที่แกว่งตามท่าเดิน คนอื่นยังเห็นลำแสงออกจากมือ

## ที่ตรวจแล้ว / ยังไม่ได้ตรวจ
- ตรวจแล้ว (รันจริงใน Studio): สร้างบ้านได้ ไม่มี error; ผู้เล่นเดินขึ้นบันไดโถงและขึ้น/ลงบันไดครัว-ใต้ดิน/ห้องทำงาน-ใต้ดินได้;
  ปีศาจเดินข้ามชั้น (ใต้ดิน→ชั้นล่าง→ชั้นบน); เก็บของ → วางที่แท่น → ได้กุญแจ ทำงานครบ; ตรวจเฟอร์นิเจอร์ไม่ขวางประตู/บันได/ช่องโหว่ด้วยสคริปต์
- **ยังไม่ได้เห็นด้วยตา**ในโหมดเล่นจริง (หน้าต่าง Studio ถูกบังขณะทดสอบ ภาพจับได้เป็นสีขาว): ความมืด, ความสว่างไฟฉาย, ลำแสงนิ่งตอนเดิน, หน้าตาห้องทั้ง 17
- **ยังไม่ได้ลองกดค้างที่ประตูหน้าด้วยการเล่นจริง** (จำลองด้วยสคริปต์ไม่ได้ในช่วงนั้น) โค้ดส่วนเปิดประตู ทดสอบแอนิเมชันเปิดแล้ว แต่ต้องเล่นจริงยืนยัน
- ตัวเลขจากตัวจำลอง (`docs/m4-research.md`, `docs/hiding.md`) เป็นของบ้านเก่า 16 ห้อง ต้องรันใหม่ก่อนเขียนเล่ม ตัวอย่างรันใหม่ (30 รอบ, บอทเก็บของ 2 ตัว): คืน 1 belief ชนะ 83% / pomcp 73%, คืน 7 belief 100% / pomcp 87% — ยังไม่ได้ปรับความยากให้บ้านใหม่
- backend ที่ deploy บน Render ยังใช้ `house_graph.json` เก่า (36 node) ต้อง push แล้ว redeploy ก่อนให้เกมส่งสถิติ (คืนที่ส่งตอนนี้อ้าง node 37–41 ไม่ถูกต้องในฝั่งเก่า)
